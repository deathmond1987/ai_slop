# Steam Calendar Companion — план работ

Сумма вишлиста: скидки, модалка скидок, скрытие цен купленных игр, переименование счётчика.

## Легенда статусов
- [ ] не начато
- [~] в работе
- [x] готово

---

## 1. Счётчик ценников вишлиста считает полную сумму некупленных игр

- [x] Счётчик в шапке показывает полную сумму некупленных игр вишлиста с учётом текущих итоговых скидочных цен.
- [x] Игры без скидки считаются по `final` цене; игры со скидкой тоже считаются по итоговой `final` цене, а их скидка показывается отдельно в модалке.
- [x] API `/api/wishlist-total` возвращает `totalCents` как основную сумму для счётчика, а также `discountTotalCents`, `discountCount` и список `discounts`.
- [x] Helper `computeWishlistPriceTotal()` возвращает `totalCents`, `discountTotalCents`, `discountCount`, `discounts`.
- [x] Тесты покрывают смысл суммы: в `totalCents` входят все неподкупленные wishlist-игры с ценой, игры без скидки не удаляются из суммы, `discountPercent` выводится из `initial`/`final`, если Steam его не отдаёт.

## 2. Модалка со списком игр со скидкой по клику на сумму

- [x] Клик по сумме в шапке открывает окно со списком игр, на которые есть скидка.
- [x] Клик по игре в окне ведёт на страницу покупки Steam (`https://store.steampowered.com/app/{appid}/`).
- [x] Данные берутся из aggregate/wishlist cache: `appid`, название, итоговая цена, старая цена, процент и сумма скидки, валюта.
- [x] Доступное модальное окно: `Esc` закрывает, клик по overlay закрывает, `role="dialog"` + `aria-modal` + заголовок, ловушка/возврат фокуса внутри окна, основной скролл страницы не блокируется.

## 3. Цены уже купленных игр убраны

- [x] На карточках игр, которые уже есть в owned/library, цена не показывается.
- [x] Такие игры не учитываются в сумме вишлиста.
- [x] Проверено, что owned/aggregate кэш не добавляет купленные игры в wishlist-сумму (исключение `sources` с `library` до подсчёта, в том числе для кэш-записей).
  - `app/api/wishlist-total` читает owned-кэш (`ownedCacheKey`) и прогоняет candidates через `markOwnedCandidates()` до `computeWishlistPriceTotal()`.
  - `wishlistCandidatesFromCacheDetails()` строит candidates из wishlist-кэша, купленные appid помечаются `library` и исключаются из суммы и списка скидок.
