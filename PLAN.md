# Steam Calendar Companion — план работ

Веб-приложение-компаньон Steam: показывает ещё не вышедшие игры (из библиотеки и вишлиста пользователя) в календарной сетке. Если у игры нет даты выхода в Steam — дата подтягивается из внешнего источника и помечается как «не из Steam».

## Стек (фактический)
- Next.js 16.4 (App Router) + TypeScript + Tailwind v4 + Turbopack
- Steam OpenID 2.0 вручную + SQLite-backed sessions (iron-session остаётся legacy fallback; NextAuth отклонён — не нужен отдельный провайдер ради одного OpenID flow)
- openid-пакет удалён из зависимостей как неиспользуемый; OpenID flow реализован вручную без пакета
- cheerio — парсинг публичного Store-вишлиста профиля пользователя без API key
- RAWG.io API — fallback-источник даты выхода, если Steam её не даёт
- SQLite (`node:sqlite`) — централизованное приложение-хранилище: TTL-кэш wishlist/library/appdetails/RAWG, users, sessions, encrypted API keys, user preferences и app secrets (`lib/sqlite.ts`, `lib/cache-store.ts`, `lib/auth-store.ts`, path через `DB_SQLITE_PATH`)
- Свой календарный грид (без тяжёлых либ)
- i18n: RU / EN переключатель (через cookie `ui_lang` и словари в `i18n/*.json`)

## Ключевые правила
1. Показываем только игры, которые ЕЩЁ не вышли (release_date > сегодня ИЛИ дата неизвестна).
2. Игры берутся из:
   - библиотеки пользователя (`IPlayerService/GetOwnedGames`, нужен Steam Web API key),
   - вишлиста пользователя (официального API нет → public Store SSR endpoint `store.steampowered.com/wishlist/profiles/{steamId}/`).
3. Если у игры нет даты выхода в Steam — ищем во внешнем источнике (RAWG) и в UI указываем бейдж «дата не из Steam» + источник.
4. Пользователь входит через Steam OpenID; API key Steam (опционально) вводит сам в настройках профиля. Если ключа нет — работает только публичный вишлист-скрейпинг (библиотека недоступна).

## Заметки / открытые вопросы
- Полный публичный вишлист за пределами первых 30 берётся keyless protobuf-запросами `IWishlistService/GetWishlist`/`GetWishlistItemCount`; public Store SSR остаётся fallback и источником первых 30 store-метаданных. Приватный keyless API не проверялся на реальном приватном профиле — при приватном SSR/API ответе приложение показывает `wishlistHidden`; если метаданные не удалось дополнить через `appdetails`, остаются placeholder/unknown.
- Даты релиза в Steam иногда «TBA» — для них всегда включаем RAWG fallback.
- В MVP не делаем уведомления/подписки, только просмотр.
- Steam OpenID `check_authentication` корректно работает только когда параметр `openid.mode` === `checkid_setup` на redirect, и `returnUrl` должен быть полностью раскрыт. Проверено curl: `/auth/login` → 307 на `steamcommunity.com/openid/login?...`.
- Next.js 16: `middleware.ts` переименован в `proxy.ts`; cookies()/headers() async; LayoutProps типизированы по href. Всё учтено.
